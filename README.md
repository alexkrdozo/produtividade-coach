# Produtividade Coach

App de produtividade que ajuda a cumprir tarefas, lembrar atividades cotidianas, acompanhar resultados e metas estabelecidas.  
Funciona como assistente pessoal e coach virtual, fazendo perguntas sobre objetivos, monitorando adesão às atividades e fornecendo feedback.

## Funcionalidades previstas
- Lista de tarefas com lembretes
- Metas de curto e longo prazo
- Perguntas de autoavaliação diária
- Relatórios de progresso
